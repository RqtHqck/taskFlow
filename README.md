# TaskFlow 🚀

Простое REST API для управления задачами без аутентификации пользователей. Позволяет создавать, обновлять и фильтровать задачи с удобным статусным workflow.

## Функциональность 📌

### Управление задачами
- Создание задач с параметрами:
    - Название
    - Описание
    - Статус (`В ожидании`, `В работе`, `Завершено`, `Отменено`)

### Работа со статусами
- Изменение статусов по workflow:
    - Взять в работу (`В ожидании` → `В работе`)
    - Завершить (`В работе` → `Завершено`) с опциональным комментарием
    - Отменить (`В работе` → `Отменено`) с опциональным комментарием

### Фильтрация и массовые операции
- Получение списка задач с фильтрацией:
    - По конкретной дате создания
    - По диапазону дат
- Массовая отмена всех задач в статусе `В работе`

## Технологии 🛠

### Backend
- **Node.js** (TypeScript)
- **Express** (роутинг)
- **Sequelize** (ORM для PostgreSQL)
- **Joi** & **class-validator** (валидация)
- **Winston** + **Morgan** (логирование)
- Централизованная обработка ошибок

### База данных
- PostgreSQL 15+

## API Endpoints 📄
| Метод  | Путь                 | Действие                                         |
|--------|----------------------|--------------------------------------------------|
| POST   | `/tasks`             | Создать новую задачу                             |
| GET    | `/tasks`             | Получить задачи с фильтрацией по дате            |
| PATCH  | `/tasks/process/:id` | Взять в работу                                   |
| PATCH  | `/tasks/done/:id`    | Завершить с опциональным комментарием "comment"  |
| PATCH  | `/tasks/abort/:id`   | Отменить с опциональным комментарием "comment"   |
| PATCH  | `/tasks/abortAll`    | Отменить все задачи в статусе "в работе"         |

## Логирование 📜
Все запросы и ошибки записываются в файл `all-logs.log`:
 - Формат логов: `combined` (Winston + Morgan stream)


## Установка и запуск 🚀

### Требования
- Node.js 18+
- PostgreSQL 15+
- Docker 20+ (опционально)

## Локальная установка (без Docker)
1. Клонировать репозиторий:
```bash
git clone https://github.com/RqtHqck/taskFlow.git
cd taskFlow
```
2. Установить зависимости:
```
npm install
```
3. Заполнить своими данными файл .env.dev по .env.example
4. Запустить проект:
```
npm run start:dev
```

## 🐳 Установка с помощью Docker
1. Клонировать репозиторий:
```git clone https://github.com/RqtHqck/taskFlow.git
cd taskFlow
```
2. Настроить переменные окружения
3. Собрать и запустить контейнеры:
```
docker compose up --build
```
4. Остановить и очистить всё:
```
docker compose down -v --rmi all --remove-orphans
```
